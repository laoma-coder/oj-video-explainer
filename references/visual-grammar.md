# 状态可视化语法

## 数组：桶计数

适用：统计 0–9、字母频次、计数排序。

一屏放 10 个格子，两行五列：

- 左上角：下标/数字
- 右上角：大号计数（0/1/2）
- 底部：两个圆点，填满表示计数
- 增量时：格子闪一下 + 轻微放大 + `+1` 上浮

```text
[ 0 ] [ 1 ] [ 2 ] ... [ 9 ]
  2     1     1          1
  ●●    ●     ●          ●
```

## 字符 → 桶：飞入芯片

适用：字符串统计。

1. 扫描框停在当前字符
2. 一个琥珀色圆片带着该数字，从字符位置飞到对应桶
3. 落点闪光，计数 +1

这比“只让数字变一下”更容易看懂“哪个字符进了哪个桶”。

## 字符串：扫描

- 每个字符一个方块
- 字母灰、数字青
- 扫描框 86×102，琥珀色边框
- 扫过的字符短暂发光

## 结果字符串：逐位拼接

适用：`res.append(...)`、答案构造。

- 底部一个 `res` 面板
- 每追加一位，出现一个字符方块
- 字符方块从下方 14px 升起，带轻微 overshoot
- 不要一行代码瞬间出现整串答案

## 代码高亮

- 高亮条高度 = 行高（46px）
- 左侧 4px 竖条 + 10% 青色背景
- 移动 0.22s，不要瞬移
- 讲完一段后可以淡出，避免一直亮着

## 左右分栏

- 16:9：左 940px 代码，右 820px 状态
- 9:16：上方代码（压缩行高），下方状态
- 字幕固定在底部安全区；不要压在代码或状态上

## 颜色

```text
背景    #070B14

次文字  #8FA3C0
青色    #22D3EE
蓝色    #38BDF8

红色    #F87171
```

## 动效

- 入场 0.4–0.6s，ease-out
- 状态变化 0.2–0.35s
- 不要弹跳过度；教学片以“看清”为第一目标
- 所有状态变化必须能只靠画面复述出来
