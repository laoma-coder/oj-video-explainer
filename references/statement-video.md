# 题意讲解片（45–75 秒）

## 目标

让第一次读题的人知道：

- 题目给了什么
- 允许做什么、禁止做什么
- 要求输出什么
- 样例为什么是这样

**不负责讲怎么做。**

## 推荐结构（60 秒）

| 时间 | 内容 | 画面 |
|---|---|---|
| 0–5s | 题号、题目名、来源 | 标题卡 + 来源 chip |
| 5–15s | 输入对象与取值范围 | 字符串/数组/图的示意 |
| 15–25s | 允许的操作与限制 | 高亮关键限制 |
| 25–40s | 用题面样例走一遍“是什么” | 样例输入 → 样例输出 |
| 40–50s | 输入输出格式 | IN / OUT 两张卡 |
| 50–60s | 收尾：先想清楚，再看答案 | 三个问题清单 |

## 禁止出现

- 做法名：排序、贪心、统计、前缀和、动态规划、二分、哈希、桶、双指针、并查集
- 完整代码、伪代码、`for` / `while` 结构
- “所以答案就是……”
- 题面没有的复杂度分析

## 允许出现

- 题目原文里的操作词：“选择”“拼成”“输出最大值”
- 样例本身的数字和结果
- “注意每个位置只能用一次”这类约束复述

## 画面原则

- 一屏一个信息点，不要同时塞题面、样例、约束
- 关键限制用颜色标出，不要靠旁白硬讲
- 样例要能“对得上”：输入里的字符和输出里的字符有视觉对应
- 结尾不要放答案，放问题清单

## 检查

```bash
python scripts/check_gates.py ./work/statement --statement
```

门禁会扫描做法词与代码块；命中就改文案，不要绕过。
