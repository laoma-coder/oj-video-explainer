# 验收门禁

## 两片共同

- [ ] `data-duration` 与音频、时间轴一致
- [ ] 画幅正确（1920×1080 或 1080×1920）
- [ ] 样例输入/输出与题面逐字一致
- [ ] 没有黑帧、文字溢出、元素遮挡
- [ ] 字幕在安全区内
- [ ] 音频峰值 ≤ -1 dBFS，无持续低频
- [ ] 代码/文案没有占位符（TODO、XXX、lorem）
- [ ] `npx hyperframes check` 通过

## 题意片

- [ ] 没有做法词：排序、贪心、统计、前缀和、动态规划、二分、哈希、桶、双指针、并查集
- [ ] 没有完整代码或伪代码
- [ ] 没有“所以答案是”
- [ ] 只复述题面，不扩展复杂度
- [ ] 结尾留问题，不揭晓做法

命令：

```bash
python scripts/check_gates.py ./work/statement --statement
```

## 答案片

- [ ] 参考代码能过样例（人工确认）
- [ ] 至少一个状态可视化（数组/栈/DP/图）
- [ ] 代码高亮与口播同步
- [ ] 讲清一个“为什么”
- [ ] 讲清一个“坑”
- [ ] 大数用 `string`，有溢出对比
- [ ] 复杂度给出

命令：

```bash
python scripts/check_gates.py ./work/solution
```

## 渲染后

```bash
npx hyperframes snapshot "--at=2,8,16,24,33,48,62,83"
ffmpeg -i out/statement.mp4 -af volumedetect -f null NUL
```

必须亲眼看的帧：

1. 标题卡
2. 第一次出现关键限制
3. 样例对应
4. 状态第一次变化
5. 答案完成瞬间
6. 总结页

## 常见失败

| 现象 | 处理 |
|---|---|
| 字被裁掉 | 提高容器高度或缩小字号，不要压安全区 |
| 高亮错行 | 检查行高与 `top` 是否一致 |
| 数字没变 | GSAP 不能用 `tl.call` 改文本，预建多状态节点 |
| 音频发闷 | 找 60–250 Hz 的持续音，换成短音 |
| 渲染慢 | 静态层预渲染，workers 降到 2 |
