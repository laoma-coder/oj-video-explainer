01 / 题目给了什么

01只含小写字母和数字

题目给一个字符串 s，只有小写字母和数字，至少有一个 1 到 9。

02 / 你能做什么

任选数字，任意顺序

9 2 1 0
字母不能选；数字可以选任意多个。

你可以挑出任意多个数字，按任意顺序拼成一个正整数。

03 / 关键限制

每个位置，只能用一次

1a01b
同一个数字出现两次，才能用两次。
1
0
1
1× 2两个 1 都能用
0× 1只有一个 0
a / b× 0字母不能选

字母不能选，数字每个位置只能用一次。

04 / 看个例子

s = 1a01b，能拼出什么？

1a01b
可以101用两个 1，一个 0
可以110换个顺序
不行111字符串里只有两个 1

比如 s 是 1a01b，可以拼出 101 或 110，但不能拼 111，因为只有两个 1。

05 / 题目要求

所有拼法里，取最大的

输出一个正整数，不是拼法数量。
101
100
♛110
11
10

要求的是：所有能拼出的正整数里，最大的那个。

06 / 输入输出

读一行，写一行

INPUT
一行字符串 s
只含小写字母和数字
OUTPUT
一个正整数
能拼出的最大值
数据范围 1 ≤ |s| ≤ 10⁶

输入一行 s，输出这个最大正整数，s 最长一百万位。
